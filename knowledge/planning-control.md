# 规划、控制与底盘

**状态：** `待验证` · **原因：** 当前仓库尚未提供足够的接口与实验记录

规划轨迹能够被生成，不等于车辆能够安全跟踪。分析“轨迹正常但车辆表现异常”时，至少要把以下延迟链拆开：

```text
规划生成 -> 消息传输 -> 控制计算 -> 底盘执行 -> 状态反馈
```

需要收集每一段的时间戳、轨迹的时间参数、车辆实际速度/转角、控制输出限幅和底盘故障状态。先用回放或封闭场地数据确定是轨迹质量、时延、模型误差还是执行器限制，再修改控制器参数。

WheelOS 路线图列出规划、控制和车辆底盘适配方向；在缺少具体版本、代码和实车指标时，AI 不应声称某个控制算法或车辆适配已经可用。
