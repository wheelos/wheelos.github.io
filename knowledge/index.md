# 自动驾驶问题库

这里按 AI 实际遇到的问题组织内容。每篇先给排查路径，再给原理；缺少 WheelOS 证据的部分会明确标为建议或待验证。

| 你观察到的现象 | 优先阅读 |
| --- | --- |
| 轨迹抖动、预测错位、融合结果不稳定 | [传感器与时间同步](/knowledge/sensors-and-time) |
| 车辆在地图中偏移、转弯方向错误 | [定位、坐标系与标定](/knowledge/localization-and-calibration) |
| 轨迹可行但车辆跟不上或控制振荡 | [规划、控制与底盘](/knowledge/planning-control) |
| 仿真通过但无法说明实车可用 | [仿真、回放与验证](/knowledge/validation) |

## 提问模板

请尽量提供：现象、复现频率、车辆或仿真环境、软件提交/版本、传感器型号、输入话题、时间戳来源、坐标系、关键日志和验收指标。没有这些信息时，结论通常只能是 `待验证`。
