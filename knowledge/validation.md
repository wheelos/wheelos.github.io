# 仿真、回放与验证

**状态：** `设计建议` · **仓库事实：** 路线图列出了 Carla 集成、可视化和调试工具方向

路线图列出 Carla 集成、可视化和调试工具方向。验证结论必须注明层级：

| 层级 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 单元/接口测试 | 数据结构和局部逻辑符合预期 | 系统级实时性和安全性 |
| 离线回放 | 在固定数据和配置下可重复 | 在线时钟、驱动和执行器问题 |
| 仿真/SIL | 场景行为和接口联调 | 真实传感器噪声、底盘动力学和道路风险 |
| HIL | 实验室条件下的软硬件时序和接口 | 未建模的场地风险和整车行为 |
| 封闭场地 | 指定车辆与场景的实测表现 | 未覆盖场景和量产安全 |
| 受控运营/公开道路/量产 | 经批准的运营范围内的运行证据 | 对其他车辆、版本和法规环境的普遍保证 |

每次实验都应保留版本、配置、场景、随机种子（如有）、数据来源、指标、失败样本和结论边界。仿真、回放和封闭场地结果可以累积证据，但不能互相替代。

安全相关项目还应把 [ISO 26262](https://www.iso.org/standard/68383.html) 功能安全、[ISO 21448](https://www.iso.org/standard/77490.html) SOTIF，以及 UL 4600 安全案例方法作为参考框架。引用这些标准不代表 WheelOS 产品或本项目已经获得认证。
