# 仿真、回放与验证

**状态：** `仓库事实 + 设计建议`

路线图列出 Carla 集成、可视化和调试工具方向。验证结论必须注明层级：

| 层级 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 单元/接口测试 | 数据结构和局部逻辑符合预期 | 系统级实时性和安全性 |
| 离线回放 | 在固定数据和配置下可重复 | 在线时钟、驱动和执行器问题 |
| 仿真 | 场景行为和接口联调 | 真实传感器噪声、底盘和道路风险 |
| 封闭场地 | 指定车辆与场景的实测表现 | 未覆盖场景和量产安全 |
| 公开道路/量产 | 特定合规条件下的运行证据 | 对其他版本和车辆的普遍保证 |

每次实验都应保留版本、配置、场景、随机种子（如有）、数据来源、指标、失败样本和结论边界。
