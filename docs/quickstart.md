# Quick Start

This guide provides a quick overview of how to get started with Wheelos Community.

## Setting up the Environment

1.  **Install Dependencies:** Follow the instructions in the [Documentation](documentation/index.md) to install the necessary dependencies.
2.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/your-username/your-repo.git](https://github.com/your-username/your-repo.git)
    ```
3.  **Build the Project:**
    ```bash
    cd your-repo
    make build
    ```

## Running a Demo

Follow the instructions in the [Examples](examples.md) section to run a demo.
