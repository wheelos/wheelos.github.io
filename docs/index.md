# Welcome to Wheelos

Wheelos is an open-source autonomous driving community inspired by "The Cathedral and the Bazaar," accelerating the development of faster, stronger, and more stable autonomous driving technology through open collaboration.

We provide open-source hardware, software, and cloud services—built upon Apollo and enhanced with our own innovations—to lower the barrier to entry and empower a thriving ecosystem of developers, researchers, and enthusiasts.

Our primary offerings are categorized into three main areas:

## Software Services

We provide a full-stack autonomous driving software solution based on localization, perception, planning, and control:

*   **Localization:** Precise positioning and mapping solutions using GNSS, IMU, and other sensor fusion techniques.
*   **Perception:** Object detection, tracking, and scene understanding using deep learning and computer vision algorithms.
*   **Planning:** Path planning, trajectory generation, and behavior decision-making algorithms for safe and efficient navigation.
*   **Control:** Vehicle control and actuation algorithms for precise vehicle control.

## Cloud Services

Our cloud services provide essential tools for remote monitoring, remote driving, and deployment of autonomous driving systems. We aim to avoid "re-inventing the wheel" by offering robust and scalable cloud infrastructure that can be privately deployed.

*   **Real-time Monitoring:** Monitor vehicle status, sensor data, and performance metrics remotely, allowing for efficient diagnostics and troubleshooting. [Learn more about Real-time Monitoring](cloud/monitoring.md).
*   **Remote Driving:** Control vehicles remotely in specific scenarios, such as testing, emergency intervention, or teleoperation. [Learn more about Remote Driving](cloud/remote-driving.md).
