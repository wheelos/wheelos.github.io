# Autonomous-driving system release roadmap

> This page describes planned objectives. It does not mean that every feature has shipped or completed real-vehicle validation.

## Wheel.OS release plan

### Version 12.31

#### Features

- **Core middleware:** support core modules and improve stability.
- **Common_msgs:** provide standard message interfaces for efficient module communication.
- **Sensor drivers:** improve support and compatibility for multiple sensors.
- **Vehicle chassis:** enable chassis control and debugging with better adaptation.

#### Tools

- **Aconf:** flexible configuration loading.
- **Cviz:** real-time visualization of key autonomous-driving data.
- **DBC_tool:** improve vehicle-chassis adaptation.
- **Chassis debugging:** support chassis diagnostics and performance tuning.

## Wheel.App release plan

### Version 2.28

- **Features:** basic localization, perception foundation, dynamic-object prediction, initial path planning and vehicle control.
- **Tools:** sensor calibration, sensor time synchronization, vehicle-dynamics calibration and CARLA bridge integration.

### Version 6.30

- **Middleware:** runtime performance optimization.
- **Hardware adaptation:** Horizon J6 and NX5.
- **Localization:** indoor localization and multi-sensor fusion.
- **Perception:** performance improvements, semantic segmentation and a robust development process.
- **Prediction:** improved behavior prediction for dynamic environments.
- **Planning:** map-independent planning and path behavior trees.
- **Control:** continued vehicle-control optimization.
- **Operations:** functional-safety work, dispatch/status management and remote driving.
- **Tools:** vehicle-dynamics modeling.

## Overview

| Version | Features | Tools | Other modules |
| --- | --- | --- | --- |
| **Wheel.OS 12.31** | Core middleware, Common_msgs, drivers, vehicles | Aconf, Cviz, DBC_tool, chassis debugging | None |
| **Wheel.App 2.28** | Localization, perception, prediction, planning, control | Calibration, time sync, dynamics calibration, CARLA bridge | None |
| **Wheel.App 6.30** | Middleware, hardware, localization, perception, prediction, planning, control | Vehicle-dynamics modeling | Functional safety, dispatch, remote driving |

## Notes

- Features are prioritized incrementally for stability and performance.
- Tool modules evolve with feature requirements.
- Operational modules will be refined in later releases to support safety and fleet operations.
